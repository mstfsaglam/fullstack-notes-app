# Fullstack Notes App

This repository contains a fullstack Notes application developed as part of the **Full Stack Open** course.

The project is structured as a small monorepo with separate frontend and backend applications.

## Structure

```text
fullstack-notes-app/
├── frontend/   # React frontend
└── backend/    # Node.js / Express backend
```
## Technologies

- Frontend: React

- Backend: Node.js, Express

- Tooling: Git, GitHub, Render

## Purpose

The main goal of this project is to practice:

- RESTful API design

- Client–server interaction

- HTTP request handling (GET, POST, PUT, DELETE)

- Error handling and middleware usage

- Deployment with Render

Each part of the application can be run and deployed independently.

## Notes

This project is primarily for learning purposes and follows the progression of the Full Stack Open course.
